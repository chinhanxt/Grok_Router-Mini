🚀 1-Chạm Thiết lập Claude Code

Sao chép và chạy lệnh phù hợp với hệ điều hành để tự động cấu hình Claude Code kết nối với AI Gateway.

Bash / Zsh Command
curl -fsSL "http://localhost:3005/claude.sh" | bash
💡 Cơ chế hoạt động: Lệnh trên sẽ tự động thiết lập biến môi trường ANTHROPIC_BASE_URL, lưu thông số models vào file ~/.claude/settings.json và cấu hình shell profile mà không cần chỉnh sửa thủ công.
