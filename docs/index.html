CỔNG BẢN QUYỀN CLAUDE CODE

Kích hoạt Claude Code bằng Key

Nhập mã bản quyền được cấp để nhận danh sách node và lệnh kết nối tức thì.

01 / CÀI ĐẶT

Lệnh kết nối theo hệ điều hành

curl -fsSL "/claude.sh?key=" | bash
irm "/claude.ps1?key=" | iex
curl -fsSL "/claude.cmd?key=" -o setup.cmd && setup.cmd

* Chạy lệnh trên trong Terminal của bạn. Sau khi hoàn tất, gõ claude để bắt đầu lập trình.

02 / MÔ HÌNH

Mô hình hỗ trợ

Model ID Tên hiển thị Mục đích sử dụng
claude-sonnet-5 Claude Sonnet 5 Mặc định cho Claude Code CLI (Tối ưu lập trình & Agent).
claude-fable-5-1 Claude Fable 5.1 Suy luận chuyên sâu cho tác vụ kỹ thuật phức tạp.
claude-opus-5 Claude Opus 5 Xử lý bài toán lớn, tổng hợp mã nguồn đa phân hệ.
claude-haiku-4-5 Claude Haiku 4.5 Phản hồi tốc độ cao cho tra cứu và tiện ích ngắn.
03 / API

Cổng kết nối (Endpoints)

Method Đường dẫn Tương thích
POST /v1/messages Anthropic Messages API (hỗ trợ SSE Streaming cho Claude Code).
POST /v1/chat/completions OpenAI Compatible API (Cursor, Windsurf, Aider, Cline...).
GET /v1/models Danh sách mô hình khả dụng.
