⚡ Zero-Database (Atomic JSON) 🔄 Tự động Failover khi 429 💻 1-Click OS Config (Bash/PS/CMD) 🛡️ Phân quyền Admin & User
01 / Kiến trúc

Thiết kế tối giản, độ tin cậy tuyệt đối

Không yêu cầu máy chủ cơ sở dữ liệu phức tạp. Toàn bộ thông tin được ghi nhận tức thì, tự động phục hồi và cách ly phân quyền an toàn.

01. FILE-BASED STORAGE

Zero-Database

Lưu trữ nguyên tử qua tệp JSON tại thư mục người dùng (~/.grok-router/). Không cần Docker, MySQL hay Redis. Khởi động trong dưới 1 giây.

02. AUTO LOAD BALANCING

AutoStrategy Routing

Thuật toán phân phối thông minh: (requestCount × 1000) + totalTokens. Tự động chuyển node tiếp theo ngay trong lượt gọi nếu tài khoản hiện tại chạm 429.

03. 1-CLICK INTEGRATION

Cấu hình 1-Click

Cung cấp sẵn script cho macOS/Linux (Bash), Windows PowerShell và CMD. Tự động ghi cấu hình vào ~/.claude/settings.json và gán biến môi trường.

04. ROLE SEGREGATION

Bảo mật phân quyền

Tài khoản Admin có toàn quyền quản lý, thêm/xóa/xuất node. Tài khoản User chỉ nhận lệnh kết nối mà không thấy token nhạy cảm.

02 / Cài đặt & Khởi chạy

Khởi động Gateway trong 3 giây

Chọn phương thức phù hợp với môi trường làm việc của bạn. Khuyên dùng NPX để luôn chạy phiên bản cập nhật mới nhất.

npx ai-claude-keyapi
npm install -g ai-claude-keyapi
ai-claude-keyapi
npx ai-claude-keyapi --port 3006
Địa chỉ Web Dashboard: Khi router chạy, mở trình duyệt truy cập http://localhost:3005 (Tài khoản Admin mặc định: admin / admin123).
03 / Quản lý & Sao lưu Node

Xuất & Nhập Node nhanh chóng

Dữ liệu node tài khoản được lưu độc lập trên máy tính của bạn. Dễ dàng sao lưu và chuyển sang máy khác chỉ với 1 thao tác.

1 Thêm tài khoản mới (Single hoặc Bulk)

Trên Dashboard quản trị:

  • Bấm nút [ + Thêm Node ] để thêm từng tài khoản (tên gợi nhớ + token).
  • Hoặc bấm [ 📥 Nhập nhiều ] và dán danh sách token (mỗi dòng một token). Hệ thống sẽ tự động khởi tạo các node tài khoản.

2 Xuất tệp sao lưu dự phòng (Export Backup)

Bấm nút [ 📤 Xuất Node ] trên giao diện quản trị. Trình duyệt sẽ lập tức tải về tệp tin sao lưu:

ai-router-nodes-2026-09-04.json

Tệp này chứa danh sách các node đang hoạt động, có thể lưu trữ an toàn hoặc chia sẻ cho các máy trạm khác trong mạng nội bộ.

3 Phục hồi khi cài lại máy hoặc đổi thiết bị

Khi bạn xóa bản cài, cài lại hệ điều hành hoặc chuyển sang máy tính mới:

  • Chạy lại lệnh npx ai-claude-keyapi.
  • Mở Web Dashboard http://localhost:3005 và đăng nhập.
  • Mở tệp JSON đã xuất trước đó, copy các token và dán vào mục [ 📥 Nhập nhiều ] để kích hoạt lại toàn bộ node ngay tức thì.
04 / Kết nối Claude Code

Kết nối 1-Click theo hệ điều hành

Khi router đang chạy, mở một cửa sổ terminal mới và chạy lệnh phù hợp với hệ điều hành của bạn. Lệnh sẽ tự động cấu hình biến môi trường và thiết lập Claude Code.

curl -fsSL http://localhost:3005/claude.sh | bash
irm http://localhost:3005/claude.ps1 | iex
curl -fsSL http://localhost:3005/claude.cmd -o setup.cmd && setup.cmd
Lưu ý: Script sẽ tự động gán ANTHROPIC_BASE_URL=http://localhost:3005 và cập nhật tệp ~/.claude/settings.json với các model tối ưu mặc định.
05 / Trải nghiệm thực tế

Hoạt động mượt mà cùng Claude Code

Claude Code nhận diện cổng router như máy chủ Anthropic nguyên bản, xử lý lệnh lập trình, duyệt file và suy luận thời gian thực.

Giao diện terminal Claude Code hoạt động với mô hình Sonnet 5 thông qua ai-claude-keyapi.
06 / Mô hình hỗ trợ

Danh sách mô hình & khuyến nghị

Router chuyển tiếp linh hoạt giữa các dòng mô hình Claude 5 và 4.5 thế hệ mới:

Model ID Tên mô hình Đặc tính & Khuyến nghị
claude-sonnet-5 Claude Sonnet 5 Mặc định cho Claude Code. Cân bằng tối ưu giữa tốc độ phản hồi và khả năng lập trình chuyên sâu.
claude-fable-5-1 Claude Fable 5.1 Khả năng suy luận cao cấp, thích hợp cho các tác vụ tác nhân (Agentic) chạy dài hạn và giải quyết bug phức tạp.
claude-opus-5 Claude Opus 5 Dành cho bài toán kiến trúc phần mềm quy mô lớn, tổng hợp mã nguồn nhiều phân hệ.
claude-haiku-4-5 Claude Haiku 4.5 Phản hồi siêu tốc, cực kỳ tiết kiệm tài nguyên cho các câu hỏi ngắn và tra cứu thông tin nhanh.
07 / Cổng giao tiếp API

Giao diện lập trình mở rộng

Tương thích cả giao thức Anthropic Messages và chuẩn OpenAI Chat Completions:

Phương thức Đường dẫn Endpoint Mục đích
POST /v1/messages Cổng Anthropic Messages API (hỗ trợ đầy đủ SSE Streaming, Tool Calling cho Claude Code CLI).
POST /v1/chat/completions Cổng OpenAI Compatible API cho Cursor, Windsurf, Aider, v.v.
GET /v1/models Danh sách các mô hình đang được định tuyến và khả dụng.
GET /api/accounts/export Xuất danh sách node dự phòng dạng JSON (yêu cầu quyền Admin).
GET /claude.sh, /claude.ps1, /claude.cmd Tải về script cấu hình tự động tương ứng theo hệ điều hành.
