ARCHITECTURE

Core Engineering Specifications

Atomic Storage
Zero database daemon. State writes atomically to ~/.grok-router/ via transactional rename. Cold start < 200ms.
AutoStrategy
Scoring metric: (requests × 1000) + tokens. Lowest score accounts dispatched first with immediate round-robin on 429.
Dual Protocol
Translates Anthropic Messages SSE streaming and OpenAI Chat Completions natively in memory. Zero external SDK overhead.
Role Isolation
Admin role owns credentials and export pipelines. Regular user tokens strictly route proxy traffic without token exposure.

DATA MANAGEMENT

Node Backup & Stateless Migration

STEP 01
Batch Ingestion
Access Dashboard and select Nhập nhiều. Paste raw API tokens separated by newlines. The routing engine provisions nodes instantly.
STEP 02
One-Click Export
Click [ 📤 Xuất Node ] to generate an encrypted snapshot ai-router-nodes-YYYY-MM-DD.json via GET /api/accounts/export.
STEP 03
Zero-Loss Recovery
Reinstalling or switching workstations does not affect the pool. Start the gateway and re-import the JSON snapshot to restore all nodes.
